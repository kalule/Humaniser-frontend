# Server CSL runtime

The .NET `CslBibliographyFormatter` runs `worker.cjs` through a local Node executable. Install Node 18 or later in the application runtime, or set `CitationCsl:NodeExecutable` to an absolute executable path (`CitationCsl__NodeExecutable` as an environment variable). No npm install, network service or credentials are required at runtime. The project copies this directory to build and publish output; keep it beside the application binaries.

The worker reads structured citation JSON on stdin and renders plain-text bibliographies or ordered citation documents with citeproc-js 2.4.63. It returns original input indices with each bibliography entry. Bibliography-only numeric styles follow supplied order; citation documents follow first-citation order and exclude uncited sources. Author/date presets sort and disambiguate the whole set, applying retroactive citation changes. Explicit narrative groups retain individually named works. It does not resolve metadata or generate academic prose.

`EssayCslCompiler` validates exact session source IDs and compiles `[S1]`, grouped tokens and explicit `[N:S1]` narratives. Publication pages are never interpreted as citation locators. Final whole-essay delivery requires successful compilation but preserves source tokens for the editor; the revision rubric receives the selected-style rendered text. Interactive co-writing also checks the exact critic-approved candidate and its cited session metadata before delivery, without rewriting approved prose or student context. Other document types and legacy renderers remain separate integration boundaries.

Limits: two concurrent workers per process; 30-second total deadline including queue time; 256 MB Node heap per worker; 500 records; 2 MiB UTF-8 request; 4 MiB response. Caller cancellation kills an active worker. Invalid, incomplete or unavailable output cannot become verified citation labels. Metadata edits remain saveable with labels cleared when formatting is unavailable; new citation saves and exports require successful formatting.

Presets and US-English locale are the same bundled snapshots used by the frontend. `csl/assets-manifest.json` records their original source URLs and SHA-256 hashes. `citeproc.cjs` is an unmodified copy of the processor source distributed by the exact npm package. Original attribution and license texts accompany it in this directory. CSL XML files retain their authors and CC BY-SA license declarations. Runtime rendering sends no metadata to upstream projects.

The server bibliography DOCX writer preserves CSL entry order and literal text, with hanging-indent paragraphs. It does not provide rich typographic emphasis. The Python citation runner is still used for metadata resolution and BibTeX export, but its custom formatting strings and DOCX sorting are bypassed by the citation service.
